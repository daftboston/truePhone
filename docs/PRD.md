# Product Requirements Document

> **TruePhone is building the most trusted marketplace for buying and selling used iPhones in Colombia.**

---

# 1. Executive Summary

TruePhone is a curated online marketplace exclusively dedicated to buying and selling used iPhones in Colombia.

Unlike traditional marketplaces where anyone can instantly publish listings, every device listed on TruePhone is manually reviewed before becoming publicly available.

Our mission is not to have the largest inventory.

Our mission is to have the most trustworthy inventory.

Trust is our product.

Every business decision, feature, and user experience should reinforce this principle.

---

# 2. Vision

To become the most trusted destination in Colombia for buying and selling pre-owned Apple devices.

When Colombians think about purchasing a used iPhone safely, TruePhone should be the first brand that comes to mind.

In the future, the platform may expand into additional Apple products and selected premium smartphones, but only if doing so does not compromise the platform's reputation for trust and quality.

---

# 3. Mission

Create a marketplace where buying or selling a used iPhone feels as safe, transparent, and professional as purchasing directly from Apple.

We accomplish this by combining technology with human review, transparent pricing, verified listings, and exceptional customer experience.

---

# 4. Product Overview

TruePhone is not a classified ads website.

TruePhone is not a general marketplace.

TruePhone is not another Facebook Marketplace clone.

TruePhone is a curated marketplace where every listing is manually reviewed before publication.

Users are not paying for access to listings.

Users are paying for confidence.

Every interaction should reduce uncertainty.

Every screen should communicate professionalism.

Every feature should increase trust.

---

# 5. Problem Statement

Buying used smartphones in Colombia is often stressful because buyers face:

- Fake listings
- Incorrect device descriptions
- Hidden defects
- IMEI problems
- Activation Lock issues
- Scam sellers
- Stolen devices
- Unrealistic pricing
- Poor communication
- No buyer protection
- No quality control

Likewise, honest sellers struggle because:

- Buyers do not trust strangers.
- They compete against fraudulent listings.
- Negotiations consume significant time.
- Many buyers never show up.
- Existing marketplaces provide little protection.

The current experience forces buyers and sellers to assume unnecessary risk.

TruePhone exists to eliminate that uncertainty.

# 6. Product Philosophy

Everything starts with one belief:

> **Trust is more valuable than inventory.**

Having fewer listings is acceptable.

Publishing slower is acceptable.

Rejecting questionable listings is acceptable.

Protecting the marketplace's reputation always comes first.

Every product decision should answer one question:

**Does this increase trust?**

If the answer is no, the feature should be reconsidered.

# 17. User Roles

TruePhone has four primary user roles. Each role has distinct permissions and responsibilities.

---

## 17.1 Guest

A guest user can browse the marketplace without creating an account.

### Permissions

- Browse listings
- Search listings
- Filter listings
- View seller profiles
- Read reviews
- Learn about TruePhone
- View Help Center
- View FAQs

### Restrictions

A guest cannot:

- Buy a device
- Create a listing
- Save favorites
- Contact sellers
- Leave reviews
- Report listings

Guests should be encouraged—but never forced—to create an account until they attempt an action that requires authentication.

---

## 17.2 Buyer

A buyer is a registered user interested in purchasing an iPhone.

### Permissions

- Purchase devices
- Save favorites
- Contact sellers
- Manage profile
- Leave reviews
- View order history
- Report suspicious listings

### Responsibilities

Buyers must:

- Provide accurate personal information
- Complete payment
- Confirm delivery
- Leave honest reviews

---

## 17.3 Seller

A seller is a registered user offering an iPhone for sale.

### Permissions

- Create listings
- Edit pending listings
- Upload photos
- Respond to messages
- View listing analytics
- Receive payments
- Build reputation

### Responsibilities

Sellers must provide:

- Accurate device information
- Original photos
- Honest descriptions
- Correct IMEI
- Accurate battery health
- Honest repair history

Providing false information may result in listing rejection or account suspension.

---

## 17.4 Reviewer

Reviewers are trusted members responsible for maintaining marketplace quality.

Reviewers are one of the core differentiators of TruePhone.

### Permissions

- View pending listings
- Approve listings
- Reject listings
- Request additional information
- Leave internal notes
- Flag suspicious accounts

Reviewers cannot:

- Modify seller information
- Change listing prices
- Edit device specifications
- Process payments

Their responsibility is verification—not content creation.

---

## 17.5 Administrator

Administrators oversee the entire marketplace.

### Permissions

- Manage users
- Manage reviewers
- Moderate listings
- Manage reports
- View analytics
- Configure platform settings
- Monitor transactions
- Handle disputes

Administrators have complete system access.

# 47. Performance

The marketplace should feel extremely fast.

Performance is part of the user experience.

Users should never feel like they are waiting for the application.

---

## Performance Goals

Home page loads in under **2 seconds** on a standard broadband connection.

Interactive elements should respond within **100 milliseconds** whenever possible.

Search results should appear in under **300 milliseconds** after the debounce delay.

Listing pages should prioritize above-the-fold content to improve perceived performance.

---

## Performance Principles

Always prefer:

- Server Components
- Server-side rendering where appropriate
- Streaming
- Incremental rendering
- Lazy loading
- Code splitting
- Image optimization
- Font optimization
- Route prefetching
- Intelligent caching

Avoid unnecessary JavaScript.

Avoid unnecessary client-side state.

The browser should download only what is needed.

---

# 49. Security

Security is a product feature.

Users trust TruePhone with personal information and financial transactions.

Every feature should be designed with security as a primary concern.

---

## Authentication

Support:

Email + Password

Google Sign-In

Future:

Apple Sign-In

Multi-factor authentication (MFA)

---

## Authorization

Use Role-Based Access Control (RBAC).

Roles include:

- Guest
- Buyer
- Seller
- Reviewer
- Administrator

Users should only access resources they are authorized to view or modify.

---

## Data Protection

Passwords must never be stored in plain text.

Sensitive information should be encrypted in transit and at rest.

Use HTTPS exclusively.

Store secrets outside the codebase.

Validate all user input.

---

## Application Security

Protect against:

SQL Injection

Cross-Site Scripting (XSS)

Cross-Site Request Forgery (CSRF)

Clickjacking

Brute-force attacks

Rate abuse

Session hijacking

Mass assignment vulnerabilities

---

## Marketplace Security
